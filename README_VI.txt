ỨNG DỤNG GHI CHÚ TỐI GIẢN – SAMSUNG ANDROID

Tính năng:
- Một màn hình soạn thảo duy nhất.
- Tự động lưu nội dung ngay khi nhập.
- Đóng/mở ứng dụng vẫn giữ nội dung.
- Không có nút Lưu, Sửa, Xóa hoặc các chức năng phụ.
- Lưu dữ liệu ngay trên điện thoại, không cần Internet.

CÁCH TẠO FILE APK BẰNG ANDROID STUDIO
1. Cài Android Studio trên máy tính.
2. Giải nén thư mục NOTE_Samsung_Android.
3. Mở Android Studio > Open > chọn thư mục NOTE_Samsung_Android.
4. Chờ Gradle Sync hoàn tất (máy cần Internet lần đầu để tải Gradle/Android Gradle Plugin).
5. Chọn Build > Build Bundle(s) / APK(s) > Build APK(s).
6. APK thường nằm tại: app/build/outputs/apk/debug/app-debug.apk
7. Chép APK sang điện thoại Samsung, mở file và cho phép cài ứng dụng từ nguồn này nếu Android yêu cầu.
